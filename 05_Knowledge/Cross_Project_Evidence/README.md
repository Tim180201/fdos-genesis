# Cross-Project Evidence

Status: Canonical Knowledge Intake

## Purpose

This area collects organizational evidence that has emerged independently in multiple FDOS projects.

It intentionally stores observations before they become organizational knowledge.

## Evidence Lifecycle

Project Observation
→ Project Evidence
→ Cross-Project Evidence
→ Knowledge Candidate
→ Pattern Candidate
→ FDOS Core (if justified)

## Rule

Cross-Project Evidence is descriptive, not normative.

Artifacts in this area must not introduce new FDOS standards. They provide the factual basis for future organizational learning.
