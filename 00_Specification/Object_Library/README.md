# FDOS Object Library

Status: Active  
Repository Baseline: v3.12.0 Clean LTS

## Purpose

The Object Library defines core organizational objects used across FDOS.

It does not create new architecture.

It clarifies the meaning, lifecycle and ownership of concepts already used by FDOS, ADO and the AI Agent layer.

## Rule

If an artifact, agent or project uses an FDOS object name, it should use the meaning defined in this library.

## Scope

The Object Library currently defines foundational terminology for:

- Evidence
- Knowledge Candidate
- Validated Knowledge
- Pattern Candidate
- Proposal
- Capability
- Reference Implementation
- Project ADO
- Decision
- Risk
- Metric
