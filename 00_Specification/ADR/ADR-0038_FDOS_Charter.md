# ADR-0038 FDOS Charter

Status: Accepted  
Version: 3.7

## Decision

Introduce a short FDOS Charter that defines the purpose and non-negotiable commitments of FDOS.

## Rationale

FDOS requires a concise orientation document that prevents the architecture from becoming self-referential.

## Consequence

Future changes must pass the Charter's final test:
Does this help the organization deliver better software faster, more reliably, more maintainably and more reproducibly?
