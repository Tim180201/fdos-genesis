# FDOS Object ID Registry

Status: Released  
Version: 3.5

## Purpose

The FDOS Object ID Registry defines stable canonical identifiers for FDOS concepts.

These identifiers enable semantic traceability between FDOS, ADO, projects, evidence and future platform implementations.

## Registry
