# FDOS Validation Projects

Status: Active Area

Projects apply FDOS specifications and reference implementations in bounded
contexts. They generate evidence; they do not redefine FDOS or its reference
implementations.

| Project | Purpose | Status |
|---|---|---|

| `Release_Evidence_Alpha/` | Validate a narrow GitHub-near release-evidence product path with controlled Technical Lead, Programmer and Reviewer roles | Level 1 experiment — Gate G1 accepted; G2 active |
