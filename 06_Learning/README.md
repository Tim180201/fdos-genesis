# FDOS Learning System

Status: Active Learning Area  
Release: Architecture Consolidation R2.8  
Scope: Additive, backward-compatible

## Purpose

The FDOS Learning System exists to continuously transform organizational experience into validated organizational understanding.

It does not develop software.

It develops organizational understanding.

Software projects remain the primary source of organizational reality, but software delivery is not the final purpose of learning.

The purpose of learning is to improve the organization's ability to make better future decisions.

## Relationship to FDOS Core

The Learning System is an organizational capability adjacent to the FDOS Core.

It does not modify the FDOS Core directly.

It may generate observations, evidence, knowledge candidates and proposals that may eventually influence FDOS through existing governance.

All Core evolution remains subject to:

- validated evidence,
- proposal review,
- human governance,
- existing FDOS change rules.

## Relationship to Projects

Projects remain responsible for delivering products.

The Learning System exists to ensure that organizational experience generated by projects is not lost.

Projects create reality.

Learning creates understanding.

Governance decides.

## Relationship to AI

AI Agents may support the Learning System.

They do not own it.

The Learning System remains an organizational capability independent of any specific AI model, agent implementation or vendor.

AI may assist with observation, summarization, analysis and proposal preparation.

AI shall not independently turn learning into organizational standards.

See also: `../01_AI/05_AI_Collaboration_Evolution.md`

## Relationship to Governance

Learning never changes organizational standards directly.

Learning produces organizational input.

Governance determines organizational truth.

Human governance remains the final authority for Core evolution, standards, capabilities and organizational decisions.

## Guiding Principle

Reality precedes observation.

Observation precedes evidence.

Evidence precedes knowledge.

Knowledge precedes organizational change.

## Compatibility

This Learning Foundation is fully additive.

It does not require changes to:

- existing projects,
- Project ADO,
- Development Agent responsibilities,
- Research Agent responsibilities,
- FDOS Core governance,
- existing standards.

## Constitutional Statement

The purpose of learning is not to automate organizational decisions.

The purpose of learning is to continuously improve the organization's ability to make better decisions.
