# FDOS Learning Architecture

Status: Foundation Architecture
Release: Learning Foundation R1.3

## Purpose

This document defines responsibilities within the FDOS Learning System.

It intentionally defines responsibilities rather than implementation details.

## Responsibility Model

### Projects
Projects create organizational reality through delivery, collaboration and operation.

### FDOS Learning System
The Learning System captures and structures organizational observations. It provides the foundation for future learning capabilities but does not make governance decisions.

### Research Agent
The Research Agent evaluates organizational observations, validates evidence, develops knowledge candidates and prepares proposals.

### Human Governance
Human Governance reviews proposals and decides whether organizational standards, capabilities or the FDOS Core should evolve.

## Responsibility Flow

Projects
↓
Reality
↓
FDOS Learning System
↓
Research Agent
↓
Human Governance
↓
FDOS Core

## Architectural Constraints

- The Learning System does not modify the FDOS Core.
- AI supports learning but does not govern the organization.
- Responsibility for organizational decisions remains human.
- Learning capabilities may evolve independently of the stable Core.

## Compatibility

This architecture is fully additive and preserves compatibility with existing projects, ADO, Development Agent responsibilities and current governance.
