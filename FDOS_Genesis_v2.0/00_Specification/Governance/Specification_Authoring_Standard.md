# Specification Authoring Standard

Every specification shall answer:

- Why does it exist?
- Which problem does it solve?
- Purpose
- Scope
- Responsibilities
- Inputs
- Outputs
- Dependencies
- Alternatives considered
- Consequences
- Evolution strategy

Quality Rules

- Evidence over assumptions.
- Stability over novelty.
- Complexity requires measurable organizational value.
- Every standard must reference validated evidence.
