# FDOS Release Specification

Defines the official lifecycle for evolving FDOS itself.

Release Lifecycle:
Idea -> Proposal -> Architecture Discussion -> Draft -> Review -> Validated -> Approved -> Released -> Observed -> Lessons Learned -> Next Release

Release Types:
- Patch
- Minor
- Major
- Kernel
- LTS

Mandatory release artifacts:
- Architecture Review
- Changelog
- Release Notes
- ADR references
- Evidence check
- Migration notes

Principle:
FDOS develops according to its own governance model.
