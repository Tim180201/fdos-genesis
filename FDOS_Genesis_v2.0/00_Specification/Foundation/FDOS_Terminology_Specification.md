# FDOS Terminology Specification

Purpose:
Defines the canonical meaning of architectural concepts used in FDOS.

Core Rule:
Every architectural term has exactly one canonical definition.

Key Definitions:
- Capability: A governed organizational ability that creates value.
- Workflow: A governed collaboration of capabilities.
- Knowledge: Validated organizational understanding derived from evidence.
- Organizational Memory: Persisted validated organizational intelligence.
- Pattern: A recurring validated organizational solution.
- Standard: A validated organizational rule approved for repeated use.
- Reference Implementation: A practical implementation used to validate the FDOS Specification.
- Project: A temporary organizational initiative applying one or more reference implementations.

Governance:
Terminology changes require Architecture Review, ADR and Evidence.
