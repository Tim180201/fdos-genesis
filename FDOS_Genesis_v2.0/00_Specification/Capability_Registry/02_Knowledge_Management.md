# CAP-002 Knowledge Management

Capability ID: CAP-002
Status: Proposed
Classification: Core Capability

## Executive Summary
Defines how organizational knowledge is captured, validated, governed, shared and evolved.

## Mission
Enable organizations to transform experience into reusable organizational intelligence.

## Purpose
Treat knowledge as a strategic organizational asset.

## Scope
In:
- Knowledge Assets
- Patterns
- Standards
- Lessons Learned
- Organizational Memory
Out:
- File storage
- Project management
- Ticket systems

## Organizational Assets
- Knowledge Assets
- Patterns
- Standards
- Anti Patterns
- Lessons Learned

## Knowledge Lifecycle
Experience
→ Observation
→ Learning
→ Knowledge
→ Candidate Pattern
→ Validated Pattern
→ Organizational Standard
→ Capability Improvement

## Organizational Memory
The governed collection of validated organizational knowledge.

## Evidence
Every knowledge asset requires evidence, review and approval.

## Core Statement
Knowledge is stored.
Intelligence is applied.
