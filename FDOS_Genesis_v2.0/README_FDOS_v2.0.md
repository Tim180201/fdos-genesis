# FDOS Genesis v2.0

This release unifies FDOS into a single repository.

Structure:
- 00_Specification : Constitutional and architectural specification
- 00_Platform..09_Business : Operational platform
- 10_Projects : Real projects
- 11_Reference_Implementations : ADO and future operating models

Migration Notes:
- Specification becomes the kernel of FDOS.
- ADO should be migrated from Projects to Reference Implementations.
- Projects (e.g. frogs.) consume Reference Implementations.
