# ADO – Role Workflow v1.0

Jede Rolle erhält:
1. aktuellen Projektstand (ZIP oder Git-Ordner)
2. aktuelle ADO-ZIP
3. genau eine ADO Case File

Die Rolle bearbeitet ausschließlich ihren Case und schreibt das Ergebnis in:
ADO/02_Results/

Dateiname:
Result_<SprintID>_<Rolle>.md

Beispiel:
Result_F003_QA.md
