# frogs. – Project Vision v1.0

frogs. ist eine digitale Zeiterfassungs-App für ein reales Nachhilfeunternehmen.

## Ziel
Die bestehende App soll innerhalb von ca. 14 Tagen stabil und produktionsreif eingeführt werden.

## Priorität
Go-live vor Perfektion. Keine großen neuen Funktionen vor Produktivbetrieb.

## Erfolg
Das Projekt ist erfolgreich, wenn Lehrer zuverlässig Zeiten erfassen können, Rollenrechte korrekt greifen, NFC oder ein stabiler Ersatzprozess funktioniert und der Kunde produktiv arbeiten kann.
