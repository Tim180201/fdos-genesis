# Prompt Policy

Codex-/Rollen-Prompts werden ab ADO v20 nicht mehr in der ZIP gespeichert.

Der Coordinator erstellt den jeweils aktuellen Prompt im Chat.

Begründung:
- ZIP bleibt reine Projekt-/Sprintquelle.
- Prompt kann situationsbezogen kurz gehalten werden.
- Codex erhält immer: aktuelle ADO-ZIP + Chat-Prompt.
