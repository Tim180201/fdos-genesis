# FDOS Reference Implementations

Status: Active Area

Reference implementations translate FDOS concepts into reusable operational
forms.

They remain separate from both the stable FDOS specification and individual
projects:

```text
FDOS Specification
→ Reference Implementation
→ Project Application
→ Evidence
→ Review
→ Targeted Evolution
```

## Active Candidates

| Reference Implementation | Status | Validation |
|---|---|---|
| `FDOS_Runtime/` | Experimental; Technical Slice 9 tested | Level 1 |

## Rule

A reference implementation may test a concept. It does not establish a Core
standard merely by existing or by passing its own tests.
